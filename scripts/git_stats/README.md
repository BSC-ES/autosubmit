# Autosubmit Git status scripts

This directory contains scripts used on different years to retrieve
statistics about the Git repositories -- first, GitLab, and now GitHub.

Before executing the next run:

- Get an API token to use;
- Review the labels used in the script, as they may have changed.

When running in the command-line terminal, use spaces in front as that
may prevent your token from being saved in the terminal history.
